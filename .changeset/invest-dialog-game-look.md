The mod's additions to the Invest dialog and the Loans tab now use the game's own look. The share
chart's grid matches the game's chart, the typed fields match the game's share count box, the order
tabs use the game's text size and colour (and are wider so "Trailing stop" fits), and the City bonds
headings and labels use the green of the loan offers beside them.
