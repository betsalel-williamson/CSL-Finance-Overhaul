# About this guide

**For:** Cities: Skylines I mayors who own Financial Districts and want to run the city's money like
a treasury: buy and hold, set orders and walk away, raise money with bonds.

**Covers:** Finance Overhaul 0.2. Each page is one feature: what you see, how to use it, and the
Options that change it. Screenshots are from the game with the mod running.

**Coming later:** dividends, recurring buys and commodities.
