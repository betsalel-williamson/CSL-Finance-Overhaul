# Install and first run

## Requirements

1. Cities: Skylines I with the **Financial Districts** DLC (it adds the Stock Exchange and Economy →
   Investments).
2. [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2040656402), subscribed and
   enabled.
3. Finance Overhaul from the Steam Workshop, enabled in Content Manager → Mods.

## First run

1. Load a city. You need a Stock Exchange to trade, as in the base game.
2. Open **Options → Finance Overhaul** and check the title shows the version (0.1.0).
3. Open **Economy → Investments**. The game's stocks are all there, plus **Index**.
4. Click the round **Stock Monitor** button in the top-left row of mod buttons.

Everything works in saves you already have, and the city still opens if you turn the mod off later
(see [Saves](./saves.md)).
