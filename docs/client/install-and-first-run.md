# Install and first run

## Requirements

1. Cities: Skylines I with **Financial Districts**.
2. [Cities Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2040656402) enabled.
3. This mod enabled in Content Manager (Workshop or
   [local install](../developer/local-mvp-install.md)).

## First run

1. Load a city that already has a Stock Exchange (or place one).
2. Open Options → **Finance Overhaul** and confirm the version title.
3. Open the Investments panel and confirm vanilla trading still works.
