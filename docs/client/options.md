# Options

Open **Options → Finance Overhaul**.

| Option                            | Default  | What it changes                                |
| --------------------------------- | -------- | ---------------------------------------------- |
| Live Stock Exchange ticker        | On       | Off brings back the game's original boards     |
| Stock Exchange ticker shows       | Change % | Change % or price and ₡ change                 |
| Show the LED ticker in info views | On       | Keep the ticker in info views or hide it there |
| LED ticker brightness             | Bright   | Classic, Bright or Brightest (daylight)        |
| Orders stay open for (new orders) | 90 days  | 30, 60, 90, 120, 180 or 365 days               |
| Order and bond notices in Chirper | On       | All mod chirps on or off                       |
| Also chirp every bond coupon      | Off      | A chirp for every coupon, not just repayments  |

**Copy build info** puts the version on your clipboard; paste it into bug reports. Stock Monitor
settings are under its own gear button (see [Stock Monitor](./stock-monitor.md)).
