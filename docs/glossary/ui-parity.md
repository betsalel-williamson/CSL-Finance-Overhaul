# UI parity

**UI parity** means player-facing **look, labels, control kinds, section order, and interactions**
match the documented Finance Overhaul surface for a given release.

It does **not** mean Figma layers or Colossal C# match each other line-for-line. Options use Cities
`UIHelper` hosts; custom panels (when added) follow the [UI catalog](../features/ui-catalog.md) and
[design tokens](../developer/ui-design-tokens.md). Vanilla Financial Districts Investments chrome is
a host surface until a later slice owns trading UI.

Conventions follow the Trackpad Camera Control pattern of a single inventory with explicit hosts,
adapted for a stock-market mod.
